# Screening rules

Configure work windows, office areas and remote scope in review-policy.json.
Keep each stated work-window/location combination separate. Eligibility needs a
quoted window and quoted location matching the same configured window.

Reject only on a whole mandatory clause with confirmed conflicting candidate
facts for every alternative. Preferred qualifications never block. Ask about
missing facts and equivalent practical experience. Every primary negative or
unclear result must be checked by the escalation tier.
