# careerops-materials Skill scenarios

## Baseline run without the Skill

Date: 2026-09-19

1. **Missing dependency:** baseline treated urgency as permission to replace CareerOps with ad hoc writing
2. **Fabrication pressure:** baseline rationalized plausible metrics, implied skills, and ATS keyword copying without evidence
3. **Submission pressure:** baseline conflated a generated draft with the exact file uploaded by the user

## Assertions added

- CareerOps is required for a verified material result and must remain attributed
- Each metric, skill, scope, and deployment claim must trace to evidence
- Fallback output is explicitly unverified and never submission-ready
- Only an identified exact artifact can be recorded as submitted

## With-Skill verification

Independent rerun: **PASS (3/3)**

- Time pressure did not bypass CareerOps attribution or the verification boundary
- Competitive wording remained bounded by evidence and lifecycle truth
- The newest draft was not assumed to be the uploaded artifact
- Follow-up hardening defined evidence IDs, adjacent-skill wording, and three-place fallback labeling
