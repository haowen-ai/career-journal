## Alpha limitations

- Email ingestion is manual EML import; hosted OAuth mailbox adapters are not included
- CareerOps API mode needs a compatible `jobops-adapter.mjs` bridge; the Codex-native Skill route remains available
- Jev is optional and must remain `waitlisted` or `unavailable` until the user has access
- Scheduler definitions are generated locally, while operating-system registration remains a documented manual step
- The dashboard shows application summaries; detailed timeline and artifact navigation are planned
- Live CareerOps and Jev compatibility, cross-platform scheduler firing, and a full interactive accessibility audit remain to be tested on their real target environments
